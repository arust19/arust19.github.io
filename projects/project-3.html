Overview

What I Built

This project is a fully custom calculator that can perform 4 basic arithmetic operations built from scratch. Starting from schematic to PCB design in Altium to soon be manufactured with hand assembled components.

A major motivation behind this project was to gain experience with Bare-Metal programming and PCB Design. For this project I am utilizing an ATtiny-1617 to act as the CPU, handling asynchronous hardware interrupts from tactile buttons. The board also contains a Unified Programming and Debug Interface header (UPDI) which will be used to program the ATtiny.

Features

What It Does

  • MAX7219 — This integrated circuit serves as the primary driver for the 7-segment display, communicating with the ATtiny microcontroller over an SPI bus.
  • USB-C — To provide a reliable power distribution network, a USB-C port is utilized to supply a steady 5V directly to a dedicated board-wide top-layer VCC polygon pour.
  • ATtiny-1617 — The CPU of the calculator; Handles asynchronous interrupts from tactile buttons in addition to arithmetic computation
  • UPDI — Integrated into the PCB is a Unified Programming and Debug Interface, allowing for seamless programming and flashing of firmware onto the microcontroller.
  • Direct-Pin Button Input — The ATtiny microcontroller contains internal pull up resistors on its GPIO pins, allowing for each button to be allocated its own dedicated pin, saving extra resistor soldering while enabling interrupt detection, eliminating CPU polling cycles.

Deep Dive

Technical Challenges

In the planning stage of this project, I had the challenge of pin management on the microcontroller. With 16 buttons, a 7-segment display, and a UPDI, the amount of available I/O pins would not be enough. While I could've gone with a matrix button layout which would've freed some pins, I decided to offload all display complexity to the MAX7219 over a 3-wire SPI interface. This design choice lowered the 12 pin 7-segment display requirement to just 3 I/O pins.

A significant portion of the design work involved component sourcing and library management. I found that standard Altium libraries lack many modern components. This lack of component resources required the manual footprint creation for the 4-digit 7-segment display from datasheet dimensions as well as careful verification of the USB-C connector's sequential pin mapping to the manufactures A/B notation.

Once the schematics were complete and PCB layout began, I quickly realized space would be the dominant challenge. Unlike my previous experience with PCB design, this project had the unique challenge of feeling like an actual hand-held calculator. With the display at the top of the board and the buttons arranged in a familiar grid that would be easy to use, I also needed to find space for each IC while satisfying requirements like decoupling capacitors, UPDI header, and routing. These requirements forced me to carefully plan ahead on the board layout, keeping the design compact while still being functional. I went through many redesigns before I could begin routing, reinforcing a fundamental lesson that placement is not just about fitting components on a board, it is about anticipating the routing before a single trace is drawn.
